# Data-User-Controll
 Sistema de controle de usuários, esse sistema é responsável por:
    - Cadastrar usuários em uma lista de usuários:
        - Usuários não podem ser cadastrados se o email já foi cadastrado no sistema
    - Exibir todos os usuários do sistema:
    - Buscar um usuário já cadastrado no sistema pelo seu nome:
        - O sistema verifica se entre os usuários na lista, algum ou muitos possuem parte do nome procurado.
